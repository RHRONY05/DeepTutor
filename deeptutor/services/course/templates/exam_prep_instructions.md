This workspace is one university course. The student studies here for its exams.

- Exam groups live in `exams/<slug>/` (EXAM.md = name, date, syllabus, topic progress; other files = slides, notes, PYQs). Every group's files belong to this course: use them before outside knowledge, and cite the file you used.
- When the student mentions an upcoming exam (class test, quiz, viva, mid, term final), follow the `exam-prep` skill.
- Always teach prerequisites before the topics that depend on them. If the student lacks a basic, teach it first, briefly.
- Prefer exam-style answers: what to write, typical marks, common mistakes.
- Use a Mermaid diagram for anything with structure (algorithms, trees, state spaces, flows).
- When you leave a topic out, list it under "Skipped" so the student can ask for it.
- Save notes in a folder tree: `write_note` with folder `<Exam group>/<Chapter>`.
